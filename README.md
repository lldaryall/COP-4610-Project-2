How to Compile and Run ### Prerequisites (Ubuntu VM) ``` sudo apt install build-essential libncurses-dev bison flex libssl-dev libelf-dev dwarves bc strace ``` ### Part 1: System Call Tracing ``` cd part1 make check ``` This builds both programs, writes `empty.trace` and `part1.trace`, and verifies that `part1` makes exactly 5 more system calls than `empty`. `part1.c` adds `write`, `getpid`, `getppid`, `getuid`, and `getgid`. It skips stdio because `printf` makes extra buffer-setup system calls. ### Part 2: Timer Kernel Module TODO ### Part 3: Install the System Calls and Kernel Run once on the VM, using the Linux 6.16.x source in `/usr/src`: ``` cd part3/kernel sudo ./apply_syscalls.sh /usr/src/linux-<version> ./build_kernel.sh /usr/src/linux-<version> sudo reboot ``` After rebooting, confirm the new kernel is running: ``` uname -r ``` ### Part 3: Build and Run the Elevator ``` cd part3 make sudo insmod elevator.ko ``` Test the system calls (run with the elevator OFFLINE): ``` cd tests make ./syscall_test smoke ``` Watch the elevator, then unload it: ``` watch -n 1 cat /proc/elevator sudo rmmod elevator ``` ## System Calls | # | System call | Returns | |---|-------------|---------| | 548 | `int start_elevator(void)` | 0 started, 1 already active | | 549 | `int issue_request(int start_floor, int destination_floor, int type)` | 0 valid, 1 invalid, `-ENOMEM` if allocation fails | | 550 | `int stop_elevator(void)` | 0 stopping, 1 already deactivating or OFFLINE | `syscalls.c` is built into the kernel and forwards each call through an exported `STUB_*` function pointer, returning `-ENOSYS` if the module isn't loaded. `src/elevator_syscalls.c` sets those pointers when the module loads and clears them when it unloads. Its first read reports current time; later reads also report elapsed time since the prior read. Build and verify it on the Linux VM with matching kernel headers: ```bash cd part2 make sudo insmod my_timer.ko lsmod | grep my_timer cat /proc/timer sleep 1 cat /proc/timer sudo rmmod my_timer test ! -e /proc/timer && echo "PASS: /proc/timer removed" ``` The tested VM used kernel `7.0.0-31-generic`. The recorded build and runtime results are in `part2/VERIFY.md`. ## Part 3: Pet Elevator The current source includes the elevator thread, scheduler, shared pet queues, and mutex-protected state.
